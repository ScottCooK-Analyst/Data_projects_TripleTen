## 📊 Overview
This project analyzes patterns in returned orders to help identify problem categories, regions, and customers with frequent returns. Tableau was used to build a fully interactive dashboard for visual storytelling.

---

## 🎯 Objectives
- Identify return trends by product category and region
- Compare return rates across customer segments
- Use filters to highlight patterns over time

---

## 🛠️ Process
- Imported and cleaned data in Tableau
- Used filters for category, region, and segment
- Designed visuals with heatmaps, bar charts, and KPIs

## ✅ Results
- Technology and Office Supplies had the highest return rates
- Most returns came from the West and South regions
- Frequent customers had slightly higher return activity
