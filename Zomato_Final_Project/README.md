## 📊 Overview
As part of the final Sprint 7 project, this dashboard analyzes customer behavior patterns for Zomato. The goal was to uncover insights about frequency, loyalty, and engagement across user types.

---

## 🎯 Objectives
- Segment customers based on behavior and return patterns
- Track new vs. repeat user trends
- Visualize purchase frequency and user value over time

---

## 🛠️ Process
- Cleaned and merged datasets in Tableau
- Built views for frequency, AOV, and engagement
- Used slicers and dynamic filters for interactivity

## ✅ Results
- Repeat customers drive more value than new users
- Weekend usage peaked in high-value segments
- Mobile users were more consistent than desktop users
