## 📊 Overview
This project explores the financial performance of a fictional superstore. Using Tableau, I created a dashboard highlighting profit trends, loss segments, and overall business health.

---

## 🎯 Objectives
- Identify underperforming segments and regions
- Visualize top products by profit/loss
- Provide actionable insights for business improvement

---

## 🛠️ Process
- Cleaned and structured data in Tableau
- Built relationships and used filters for dynamic views
- Developed visuals for profit breakdown, loss heatmaps, and product performance

## ✅ Results
- Central region had the highest losses in furniture
- Certain sub-categories showed repeated negative returns
- Highlighted opportunities for inventory reevaluation
